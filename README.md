# BTO AI Music Composer
**Owner-approved source baseline for Public GitHub** — Rev.0 Draft 05 (2026-11-14).

AI Agent for writing original songs: a one-sentence idea in, **complete Lyrics + Styles** ready to paste into Suno out. No Excel. The Agent offers guided choices when needed, while accepting "Tự đề xuất" for quick composition.

**Active library:** 10 F02 Rev.5 EXT Styles, not the former 72 SL Styles. Source: `references/EXT_Style_Library_10_Rev5.json`.
**Suno Styles format:** 10 fields ordered Mood, Vocal, Genre, Tempo, Instruments, Production, Structure, Language, Theme, Avoid; 900–950 Unicode characters including LF separators.
**Text validation:** `python tools/check_library.py`.

Read `START_HERE.md`, then numbered contracts 01–10 and the dialogue/test documents.

**Important:** Approval covers this Skill's source delivery to Public GitHub. Individual Styles remain unapproved Release Candidates; musical/Suno audio QA has NOT RUN. No open-source license chosen yet. No claim of finished music production approval.
